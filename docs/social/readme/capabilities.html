What is inside

One engine. Six things it does well.

Packs are files, so a new industry is a directory, not a project. The same engine runs a shop from CSV exports and a GPU fleet from live signals.

01

Sense

Your data, read-only

  • CSV, JSON, Prometheus, SQL, REST, Kubernetes
  • Webhooks in, manual values audited
  • Stale inputs flagged and penalised
02

Model

A KPI graph you can read

  • Targets, owners, criticality
  • Cause-and-effect edges you declare
  • Backtested against real outcomes
03

Decide

Ranked, with the reasoning

  • What-if with prediction ranges
  • Gap closed minus risk
  • Hard constraints refused, not buried
04

Ask

AI that explains, never decides

  • Grounded answers that list their facts
  • Read-only. A local model works air-gapped
  • Heuristic mode needs no model at all
05

Approve and act

Control stays with you

  • Roles, SSO, quorum, change windows
  • Re-checked right before it runs
  • kubectl, webhook, file or a person
06

Prove

Evidence you can hand an auditor

  • Hash-chained audit trail
  • Ed25519-signed decision records
  • Verify an export offline
