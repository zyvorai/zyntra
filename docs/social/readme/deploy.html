Zyvor ZyntraDeploy
Runs where you run

From laptop to cluster in one command.

No SaaS dependency and no database to babysit. Air-gapped installs work, and a local model can sit behind Ask.

Binary

One static Go binary with the console built in. Run it under systemd.

Container

Signed multi-arch image on GHCR with SBOM and provenance, amd64 and arm64.

Compose

A single file for a small team: Zyntra plus the test receiver.

Helm

OCI chart. Non-root, read-only root filesystem, state on a PVC, keys generated once.

k3s or in-cluster

One script for a k3s host. In-cluster mode reads through a read-only role, no kubectl.

helm upgrade --install zyntra oci://ghcr.io/zyvorai/charts/zyntra -n zyntra --create-namespace --set pack=shop
